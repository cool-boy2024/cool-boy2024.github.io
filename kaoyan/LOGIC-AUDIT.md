# 2026-10-25 学习系统逻辑审查

## 范围

检查计划、打卡、计时、知识点、日志、AI上下文与应用、薄弱判定、复习、撤销、图片、会话、多标签页、03:00换日及私有云同步。测试使用独立浏览器和模拟数据，不改动真实学习记录。

## 已修复的闭环缺口

| 问题 | 结果 |
| --- | --- |
| AI不知道打卡、过去任务、专注记录、知识点笔记和已完成复习 | 传入有长度和日期限制的上下文，明确区分未打卡、未学和未掌握 |
| 进度摘要容易被理解为整科任务已打卡 | 保持本人勾选，增加“核对今日打卡”入口 |
| 待确认薄弱点可能提前产生复习 | 先保存建议，本人确认后才加入复习；只是落后不自动进入待攻克 |
| 复习已掌握与薄弱专栏状态互不联动 | 同一科目、同一主题双向联动，重新巩固可恢复 |
| 复习改期只是新增，旧项仍逾期 | 添加按已有id改期的输出协议和前后端验证 |
| 已完成复习无法回看，误添加无法移除 | 增加已完成/移除记录与恢复入口 |
| 刷新丢失撤销，纯聊天覆盖撤销 | 本机保留最后有效调整；后续编辑阻止过期撤销 |
| 原样返回计划会清除已完成勾选 | 过滤无实际变化的任务；完成状态绑定任务内容 |
| 正在发送时输入新草稿/换图会被返回结果清空 | 发送期间锁定文字和照片选择，出错保留输入 |
| 不支持的照片无法取消，后续文字也发不出去 | 提供取消照片入口；错误base64返回明确的400校验错误 |
| 多标签页或计时每秒写整个旧状态覆盖新记录 | 写前按字段合并、监听其他标签页更新；计时独立暂存 |
| 本机存储失败可能留下半次AI修改 | 先生成完整状态，持久化成功才替换；变更与回复同次保存 |
| 03:00后复习提醒和日志日期还停在昨天 | 换日统一刷新任务、统计、日志日期和复习列表 |
| 断开云同步后，未结束的读取继续合并/上传 | 用连接版本检查中断后续步骤；网络请求加30秒超时 |
| Cloudflare访问验证到期返回HTML，前端显示JSON解析错误 | 明确提示重新验证，刷新保留文字草稿 |
| 对话/复习多于40条后无入口查看 | 添加更早消息和更多待复习入口 |

## 验证

32项后端/日期/计划自动测试，以及4组浏览器流程测试：基础UI、会话与薄弱确认、照片、完整逻辑回归。

完整逻辑回归覆盖：待确认到复习、掌握与重开、已有复习改期、移除与恢复、刷新撤销、普通聊天保留撤销、相同计划保留勾选、等待期间并发编辑、照片错误恢复、存储空间失败的原子性、多标签页与计时、凌晨换日、断开云同步时的请求竞态。

## 仍需明确的边界

1. AI登录和跨设备学习数据同步相互独立。新设备仅登录AI不会自动得到旧记录，需要连接同一个私有数据仓库。
2. 同一条记录的两台设备并发编辑仍采用时间戳较新版本，不是协同编辑器。切换设备前先同步；设备时钟偏差也会影响排序。
3. AI自动调整只覆盖未来14天；更远的固定阶段计划不随一次局部调整自动整体重写。
4. 提醒仅在网站内显示；没有系统推送。照片原图也不保留，后续讨论原图要重新上传。
5. 任务勾选、知识点掌握与具体薄弱主题是不同粒度，不自动互相推断。计时不证明掌握。
6. AI仍可能给出不合适的学习建议。格式校验、实际改动明细和撤销用于降低误改影响，不能保证建议本身永远正确。

线上边界：部署成功，GitHub发布检查通过；域名和Worker入口当前都有Cloudflare Access保护，未登录的自动HTTP检查返回登录页。本轮未能完成受保护生产页面中的真实模型回归，未修改访问保护。


## 2026-10-26 连接可靠性修复

现场无登录 HTTP 探测确认：主域名和 workers.dev 的首页、/auth/session、ai-coach.js 均返回302并跳到 Cloudflare Access。不能据此断言用户截图的每次失败都只有这一个原因；旧截图仍显示原生 Failed to fetch，也与当时已发布的中文错误处理不一致。

本次新增：手动识别访问验证重定向，区分登录/网络/服务异常；传输失败限次重试；同请求ID和正文重试、单实例去重；网络恢复检查会话；可点击恢复操作；版本提示与草稿找回；云同步有限退避恢复。既有访问保护不变，外部网络、服务故障仍可能暂时阻断回复，不承诺永久在线。

已验证38项单元测试、6组隔离浏览器流程（原4组加网络恢复、云同步恢复），以及最终Worker静态包的版本和JSON路由。新增用例覆盖：请求丢失后重试正文/ID一致，回复只应用一次；302验证不自动重发；HTML503有限重试；余额不足不重试；会话过期后登录继续；断网到恢复不自动发草稿；旧版失败消息找回；版本升级保留草稿；云同步退避耗尽暂停、401停、主动断开取消恢复。生产真实模型回归仍受 Cloudflare Access 登录状态限制。
